## 快速开始

本项目统一使用 [Deno](https://deno.com/) 管理依赖、运行脚本和执行 TypeScript
检查。

在项目根目录安装所有子项目依赖：

```sh
deno task setup
```

检查所有子项目类型：

```sh
deno task check-type
```

格式化和检查格式：

```sh
deno task fmt
deno task check-fmt
```
