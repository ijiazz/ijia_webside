## 数据库设计
考试相关表定义在 db/init/table/public/examination/examination.sql

## 正式考试流程

- 试卷生成
  - 不同场景下根据特定规则创建 exam_paper_template 记录，本添加题目到 exam_paper_template_question 表与之绑定
- 分发考试
  - 给用户创建一个 examination 记录，并关联 exam_paper_template，此时用户能够看到自己考试的信息；
- 用户作答
  - 在考试允许范围内，用户可进入考试
  - 考试可能存在总时间限制
  - 用户只能按顺序作答，提交题目后可继续作答下一题
  - 题目可能存在时间限制
  - 交卷后，才允许查看作答记录
  - 成绩统计完成后，才能查看考试结果，作答记录才显示正确答案和得分

## 模拟考试题目生成规则

这个逻辑先跳过，标记 TODO

下面是草案

- 模拟考试只能生成 collection_level <=1 目且审核通过了的人工题目
- 如果需要生成系统题目，则需要新生成，再添加，不能直接使用题库中已存在的系统题目
- 根据设定的单选、多选、判断题的比例，生成题目

## 接口

考试相关接口定义在 web_dto/src/exam/examination.ts

### 接口测试

定义一个用于测试用的生成题目的函数

- 创建考试
  - 模拟考试
    - 允许用户给自己创建模拟考试，创建的试卷模板应为 null
- 获取自己的考试列表
- 开始考试
  - 开始考试时，根据模板信息生成系统题目（如果需要）并关联题目
- 删除考试
  - 可以删除自己的考试
  - 删除不存在的考试时，应返回 404
  - 删除别人的考试时，应返回404
  - 删除考试时，模板应被一起删除
    - 模板被删除时，关联的系统题目应一起删除
- 获取考试信息
  - 获取自己的考试信息
  - 获取他人的考试信息应返回 404
- 作答获取下一题
  - 获取下一题应该是按顺序且没提交的题目
  - 获取别人考试的题目应返回 404
- 提交答案
  - 提交他人考试的题目信息，应返回 404
  - 已经提交的题目，再次提交应返回 409
  - 提交为开始作答的题目，应返回 409
  - 交卷后，不能再继续作答
- 交卷
  - 交卷别人的考试，应返回 404
- 作答记录
  - 交卷前，查看作答记录应 返回 409
  - 成就统计完成前，查看考试接口应返回空，在统计完成后，才能查看考试结果
- 流程
  - 生成一个有三个题目的考试，正确作答1题，错误作答一题并直接交卷，然后查看考试结果、作答记录
  - 生成一个有三个题目的考试，全部作答正确并交卷，然后查看考试结果
  - 生成一个有三个题目的考试，正确作答1题并直接交卷，然后查看考试结果
  - 生成一个有三个题目的考试，全部错误作答，并交卷，然后查看考试结果
  - 生成一个没有题目的考试，提交并交卷，然后查看考试结果、作答记录

## 前端

- 在个人主页下添加一个 ”我的考试“ tab, 仅自己可见，添加一个锁的图标
  - 可从”我的考试“进入考试详情
  - 可操作删除考试
  - 显示考试状态、考试时间范围、名称
  - 列表顶部添加一个”模拟考试“按钮，可用于创建模拟考试，创建成功后跳转到考试详情页
- 考试详情页
  - 添加返回按钮，可返回前一个页面或考试列表
  - 考试相关信息
    - 名称
    - 允许考试的时间范围
    - 状态
    - 题目总数
    - 总分
  - 考试结果信息。（出结果后展示）
    - 得分
    - 正确数
    - 错误数
    - 未答题数
    - 总用时
  - 题目索引。交卷后展示（用带题号的方块排列，用颜色区分是否正确），固定在头部，不要随作答记录滚动而滚动
    - 颜色对应状态
      - 蓝色：未知结果
      - 灰色：未答题
      - 红色：错误
      - 绿色：正确
      - 黄色：部分正确
    - 点击题号定位到作答记录
  - 作答记录列表。（交卷后展示）
    - 复用题目组件
    - 用颜色区分正确、错误、部分正确、未出结果
    - 展示难度，用星星表示
    - 展示出题人，点击出题人可以跳转到出题人主页
    - 展示正确答案(如果有)
    - 作答用时，单位秒
  - 开始考试按钮。（交卷前展示）
    - 如果未到开始考试时间，则禁用
    - 如果已经开始考试，文案显示为”继续考试“
- 考试页面
  - 顶部显示考试标题，总用时
  - 题目复用题目组件
  - 显示当前题目用时。如果题目有时间限制，则显示倒计时
  - 加一个选项：”提交后自动开始下一题“
  - 提交选择的答案后，如果勾选了”提交后自动开始下一题“，自动开始下一题，如果未勾选，则停留在当前题目，提交按钮隐藏，显示”下一题“
  - 如果题目全部作答完毕，则显示”结束考试“
  - 点击”结束考试“后，返回题目详情页
